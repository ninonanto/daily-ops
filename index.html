Import system sales (Sale Order export)

Choose the Sale Order export from the charging system (.xlsx, .xls or .csv). The page reads it here in your browser, totals it by day, station, charger and hour, and saves only those totals to the Sheet — not each order. For every date and station in the file, what is stored is replaced; other stations and dates are left alone. Re-importing the same file is safe. Daily routine: import yesterday's full-day export each morning.

Only an Admin can import sales.
